# jiffy-75
Official resources for the JIFFY 75 split ergonomic keyboard, including documentation, firmware, VIA configuration files, software, and technical support.

## details

* JZFHub config software can be found at [jzfhub.com](https://jzfhub.com)
* [Jiffy75说明书v1.1_英文(1).pdf](Jiffy75说明书v1.1_英文(1).pdf) is the English version of the manual
* [https://docs.channel.io/jezailfunderjp/ja/articles/Jiffy75-LP-%E6%97%A5%E6%9C%AC%E8%AA%9E%E3%83%9E%E3%83%8B%E3%83%A5%E3%82%A2%E3%83%AB-1773ff82](https://docs.channel.io/jezailfunderjp/ja/articles/Jiffy75-LP-%E6%97%A5%E6%9C%AC%E8%AA%9E%E3%83%9E%E3%83%8B%E3%83%A5%E3%82%A2%E3%83%AB-1773ff82) contains a Japanese manual that can be translated using the built in Google Translate functionality in Google Chrome. It had more details than the PDF English manual included in this repo
